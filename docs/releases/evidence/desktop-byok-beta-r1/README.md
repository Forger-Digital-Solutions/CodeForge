# Desktop BYOK Beta R1 Evidence

This directory is reserved for immutable evidence generated from the exact
candidate commit. Evidence must contain no credentials, provider API keys,
private source, or CI secrets.

The current workspace has source-level and automated-test evidence, but no
Windows packaged artifact was produced locally. A Windows CI run on
`windows-2022` is required before this directory can contain package hashes,
packaged smoke results, screenshots, or an artifact-specific dependency audit.
