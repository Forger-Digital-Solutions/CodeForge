# CodeForge Free Provider Policy

1. `managed_free` is denied by default.
2. A user-owned account may be used only as Direct or BYOK; it must never fund other users.
3. Trial, promotional, evaluation-only, account-, project-, and organization-scoped allowances are
   not pooled capacity.
4. A managed route requires explicit written downstream authorization, a recorded zero-cost
   commitment, a configured hard spend ceiling, policy/region/privacy compatibility, live health,
   and current 8-Bit qualification.
5. Loss of any requirement immediately removes the route from ForgeAuto and results in a truthful
   unavailable/cooling-down/pending state. It never triggers a paid fallback.
6. The provider's upstream terms control availability. CodeForge's own user allowance does not
   create upstream capacity.
