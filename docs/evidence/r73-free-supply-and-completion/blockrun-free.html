Free · 7 OSS Models

Free LLM API.
No key. No wallet.

7 open-source models, free through BlockRun. No key. No wallet. Six ways to call any of them.

curl
curl https://blockrun.ai/api/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nvidia/nemotron-3.5-lightning",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

↑ Paste in any terminal. Returns 200 with a chat completion.

What actually answers

A free model can be busy.
Your call still returns 200.

Free capacity is borrowed, not reserved, so at any moment some of these models are saturated. When the one you named is, we answer with another free model instead of failing the request. On 2026-09-21 five of the six were busy and all six calls returned 200.

The reply always tells you which one answered. Read the model field rather than assuming you got the ID you sent:

# you asked for one model
"model": "nvidia/nemotron-3.5-lightning"

# the reply names what actually served it
"model": "nvidia/nemotron-3-super-120b"

That is the trade for paying nothing. If you need a specific model to be the one that answers every time, that is what the pay-per-call side is for — same endpoint, same request, and the model you name is the model you get.
