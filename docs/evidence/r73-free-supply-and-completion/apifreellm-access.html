How it works

Sign in with Google and use your API key as 'Bearer YOUR_API_KEY'. Community is free, Best-Effort and subject to rate and daily limits; Managed consumes paid credits.

API Endpoint

Send POST requests to our endpoint. Use your API key as the Bearer token in the Authorization header.

POST https://apifreellm.com/api/v1/chat

Request Body

message

(string, required) - Your message/prompt to the AI

model

(string, optional) - Default: apifreellm (optional)

Headers

Content-Type

application/json

Authorization

Bearer YOUR_API_KEY (required - your API key)

Windows PowerShell

Invoke-RestMethod -Uri "https://apifreellm.com/api/v1/chat" -Method POST -Headers @{
    "Content-Type" = "application/json"
    "Authorization" = "Bearer YOUR_API_KEY"
} -Body '{"message": "Hello, how are you?"}' | ConvertTo-Json

Response Example

{
  "success": true,
  "response": "Hello! I'm doing great, thank you for asking...",
  "tier": "community",
  "features": {
    "bestEffort": true,
    "dailyRequestLimit": 50,
    "priorityProcessing": false
  }
}

Python

import requests

response = requests.post(
    "https://apifreellm.com/api/v1/chat",
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer YOUR_API_KEY"
    },
    json={
        "message": "Hello, how are you?"
    }
)

print(response.json())
