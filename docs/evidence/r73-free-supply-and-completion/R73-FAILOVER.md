# R73 failover evidence

R73 preserves one Free routing fabric and its cost, privacy, qualification, quota-owner and health gates. Reviewer replacement has three bounded candidates, cumulative route exclusions, preserved implementation/diff and durable routing constraints. It never replays the successful Coder edit merely to try another Reviewer. Exhaustion terminates blocked rather than approving a change.

## Deterministic recovery

`reviewer-recovery-tests.json`, `reviewer-parent-regression-tests.json` and the subsequent focused receipts exercise production parent orchestration, malformed Reviewer replacement, rate-limit rotation, durable exclusions, final ForgeVerify/integration and bounded exhaustion. Scripted providers are explicitly test providers. Existing provider suites cover HTTP errors, HTTP-200 error envelopes, empty choices, stream interruption/timeouts, authentication and tool normalization. These controlled failures prove the code paths, not an organic live-provider recovery.

Kilo's witnessed exact requested-model upstream limit is now classified at model scope. Explicit account/IP limits override that narrowing; unknown/mismatched-model evidence remains provider scope. No new physical quota is manufactured by changing the cooldown key. Liquid's live error and `kilo-upstream-scope-tests.json` support the fix. Poolside's upstream-account 429 remains conservatively provider-scoped because it does not prove an independent model domain.

BlockRun's witnessed misleading HTTP429 `FREE_MODEL_FAILED` envelope named an upstream NVIDIA400 invalid-JSON tool-parser failure. The narrow adapter classification is `INVALID_TOOL_OUTPUT`; it does not exhaust the source-IP allowance. A genuine Free-tier limit still applies to the whole source-IP domain. Executable streamed tool completions remain buffered until final exact-model validation and non-aborted successful finish.

## Organic evidence and limits

Live Reviewer qualification observed Kilo organic SSE/in-band502, exact-model429, upstream-account429 and other upstream failures. BlockRun catalog availability changed organically. These receipts are retained without deliberate quota exhaustion, proxy rotation or paid fallback.

No successful automatic continuation through a different eligible provider has yet been demonstrated in a completed live parent task. The first production campaign blocked on Coder turn exhaustion after a correct edit and passing tests; its initial BlockRun catalog was unavailable, and no Reviewer inference occurred. Its failure is not labeled a provider outage. The mandatory organic cross-provider completion gate remains open until a direct live receipt proves the outcome.

See `R73-AUTONOMOUS-COMPLETION.md` and `reliability-summary.json` for the final live task outcomes; injected recovery must not substitute for gate H.
