Getting started

Sign in on the API access page, create or retrieve your API key, and store it as a server-side secret. Send it in the bearer authorization header.

curl https://apifreellm.com/api/v1/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"message":"Explain exponential backoff in one paragraph"}'

Endpoints

  • POST /api/v1/chat: simple message endpoint available to authenticated keys, with service-class limits.
  • POST /api/v1/chat/completions: OpenAI-compatible managed endpoint for eligible paid access.
  • GET /api/v1/models: model discovery for OpenAI-compatible clients.

OpenAI-compatible API

The managed endpoint accepts an array of messages with roles such as system, user and assistant. The public model alias is apifreellm, so upstream model changes do not require application changes.

The endpoint currently accepts stream, temperature, max_tokens, tools and tool_choice. Test the exact behavior required by your application before release.

Community Best-Effort limits

The community route is intended for exploration and light interactive development. Requests may be rate-limited, cloud or datacenter traffic may be restricted, and shared providers can fail. Always handle 429 and 5xx responses.

  • Do not use the community route as a production availability dependency.
  • Respect Retry-After when it is present and use capped exponential backoff.
  • Set client timeouts and avoid automatic retry storms.
  • Never embed an API key in browser or mobile application source.

Managed API usage

Managed plans use credits and transparent upstream costs rather than an unlimited promise. Usage controls and applicable plan details are shown in the authenticated product experience. A 429 can indicate a rate or usage boundary; do not retry it immediately.

Errors and retries

  • 400: invalid JSON or request fields. Fix the request; do not retry unchanged.
  • 401: missing or invalid API key.
  • 403: service class or network is not eligible for the endpoint.
  • 429: rate or usage boundary. Honor the response and retry later.
  • 5xx: temporary upstream or service failure. Retry a small number of times with jitter.

Security and data

Keep keys in a secret manager or server environment variable, rotate exposed keys immediately, and avoid sending secrets or personal data that the model does not need. Review the privacy policy before processing user content.
