# R84 reviewer reliability

R84 reused the existing OpenAI-compatible adapter and ForgeAAA reviewer, rather than adding another review authority. The adapter rejects a [DONE] trailer without finish_reason, malformed JSON and in-band upstream errors, propagates Retry-After and rate-limit observations, and releases the stream reader. A complete terminal signal and exact served model are required for independent review. Reviewer schema now validates summary, finding ids, categories, severities, messages, evidence and verdict consistency. Evidence is rejected before dispatch if oversized; it is never clipped. One callback dispatch is allowed; there is no unqualified or paid fallback.

The R82 live request [timed out](r82-review-0e681d9b-bafb-4400-b022-603225f58cec.json). The R83 request [completed with stop, exact model and valid schema](r83-review-620d8e2f-d5f7-415d-9839-3a5091a46974.json) but returned revision_required. Both were destination-approved public evaluation requests, each capped at 120 seconds and 6,000 output tokens. The initial transmission was withheld until that consent arrived. The attempt UUID is a local id; an upstream request id was not reported by that script version.

Historical source packets had 75,516 and 77,413 characters and contained stale milestone knownFailures. The model treated those as current, despite the appended correction. The preserved verdict is not certification. The new deterministic [packet index](current-review-packets.json) points to 31,353-character packets with current receipts, retained failures and selected migration authority source. These are PREPARED_NOT_SENT. Preparing or self-reviewing them is not independent acceptance.

The script now accepts these content-hashed packets, validates their identity, and records an upstream request id if returned. Legacy callbacks returning only text remain type-compatible but cannot certify a run. Existing historical benchmark scripts therefore need structured completion metadata before their reviews can approve. Historical evidence is untouched.
