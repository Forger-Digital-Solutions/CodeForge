# R36 — Before / after

| Surface | Before (R35 UI) | After (R36) |
|---|---|---|
| Live commands | invisible in feed | command cards w/ transcript, cwd, exit, duration |
| Steering | invisible | "You · steering" rows |
| Subagents | flat system text | role/task/state/progress rows |
| Capacity wait | header only | honest feed notices + sidebar parked state |
| Browser tools | generic "Activity" | browser identity + Inspector action log |
| Grouping | same-kind only, no timing | mixed-kind groups, elapsed, per-kind counts |
| Assistant prose | label on every row | one label per run |
| Commands tab | plain list | transcripts, cwd, durations, interrupted |
| Changes tab | no inline diff | expandable rows → inline diff |
| Inspector | fixed width | drag-resizable |
| Files view | dead stub | real FileExplorer |
| Icons | emoji-heavy | monochrome set, new activity kinds |
