# Free-product access patterns checked 2026-10-01

| Product | Quota owner / access | CodeForge decision |
| --- | --- | --- |
| [Kilo Gateway Auto Free](https://kilo.ai/docs/gateway/authentication) | Anonymous free requests: public IP, documented 200/hour/IP. [Gateway terms](https://kilo.ai/terms) discuss third-party apps. | Implemented pinned installed-client transport. Public-code admission only, subject to real qualification. |
| [OpenCode Zen](https://opencode.ai/docs/en/zen/) | Zen login and API key; some lab models free for a limited time. Exceptions to the general zero-retention policy are named per model. | Sponsorship lifecycle reference. No use of Zen credentials or private interface. |
| [Gemini Developer API](https://ai.google.dev/gemini-api/docs/rate-limits) | Free quota is per project, not key. [Google's OAuth guide](https://ai.google.dev/gemini-api/docs/oauth) requires an enabled Cloud project and, for external production use, verified authorization scopes. [Free-tier pricing](https://ai.google.dev/gemini-api/docs/pricing) lists product-improvement data use. | Sanctioned OAuth exists, but no zero-setup CodeForge project delegation or free-tier account attestation is implemented. The available environment key is not proof of a Free project; no inference was attempted with it. |
| [GitHub Copilot SDK](https://docs.github.com/en/copilot/how-tos/copilot-sdk/features/usage-and-billing) | Official SDK exposes account quota and model credit pricing for the authenticated user's entitlement. | Sanctioned user-entitlement candidate. The existing registry remains gated until account-specific Free eligibility, overage hard stop, privacy and managed relay terms are established. No new integration is claimed. |
| [Cline public API](https://github.com/cline/cline/blob/main/docs/api/getting-started.mdx) | Official OpenAI-compatible API requires a Cline account and API key; its guide includes a no-credit Free-model example. | Legitimate user-account or sponsor candidate, requiring separate quota, terms, privacy and no-paid-fallback verification. No CodeForge account access or admitted route is claimed. |
| [OpenRouter Free](https://openrouter.ai/pricing/) | [OAuth PKCE](https://openrouter.ai/docs/guides/overview/auth/oauth) authorizes a user's own account without typing a key. Free accounts currently list 50 requests/day; model catalog prices are dynamic. The [current-key API](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-key) exposes `is_free_tier`. | Existing desktop OAuth path is legitimate per-user access. A live `:free` model returned a tool call and zero usage cost in this round, but the available environment key reported `is_free_tier=false`; it is owner/dev access, not an admitted Packaged Free product domain. |

[Groq Free](https://console.groq.com/docs/rate-limits) documents organization-level Free limits, while [project documentation](https://console.groq.com/docs/projects) describes project-specific keys and limits. This requires account/project identity and tier evidence before CodeForge can count a distinct managed Free domain. No Groq Free account tier was verified in this round.

These references establish quota placement and product patterns. They do not admit a CodeForge route without current terms, privacy, cost, qualification, and runtime receipts.
