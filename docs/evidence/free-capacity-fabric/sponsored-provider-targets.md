# Sponsorship outreach targets

Potential targets, not agreements or admitted routes:

- Model labs presently offering limited-time models through [OpenCode Zen](https://opencode.ai/docs/en/zen/): ask for a direct commercial-agent allocation, explicit quota pool, data policy, term, and expiry.
- Providers behind [Kilo Auto Free](https://kilo.ai/docs/gateway/models-and-providers): ask whether a CodeForge sponsor pool with private-code-safe terms is available. Kilo's current Auto Free privacy warning prevents confidential-code admission.
- [Cline's documented Free-model API](https://github.com/cline/cline/blob/main/docs/api/getting-started.mdx): clarify a dedicated sponsor grant, quota ownership, commercial application terms and data policy. The public API exists; CodeForge has no grant or admitted account route yet.
- Inference providers offering public zero-price models: ask for a dedicated CodeForge sponsor pool with stable commercial terms and telemetry for fair scheduling.

An offer enters `PROPOSAL`; it cannot become `PROMOTED` until terms, commercial use, privacy, price funding, quota, tool qualification, and a canary receipt are recorded. The current code enforces lifecycle transitions and contains a fail-closed offer materializer, but no remote operator pipeline or signed manifest transport yet. No outreach has been sent and no agreement is claimed.
