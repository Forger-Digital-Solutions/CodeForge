This enables accurate billing even for very low-cost requests.</p><h2 id="how-billing-works" class="heading">How billing works</h2><p>Every request to the gateway follows this flow:</p><ol><li><strong>Balance check</strong>: Before proxying the request, the gateway verifies you have sufficient balance</li><li><strong>Request execution</strong>: The request is sent to the upstream provider</li><li><strong>Usage tracking</strong>: Token counts and costs are extracted from the response</li><li><strong>Balance update</strong>: Your balance is atomically updated with the request cost</li></ol><h3 id="cost-calculation" class="heading">Cost calculation</h3><p>Costs are determined by the upstream provider&#x27;s pricing based on token usage:</p><ul><li><strong>Input tokens</strong>: Tokens in your prompt (system message, user messages, tool definitions)</li><li><strong>Output tokens</strong>: Tokens generated by the model</li><li><strong>Cache write tokens</strong>: Tokens written to the provider&#x27;s prompt cache</li><li><strong>Cache hit tokens</strong>: Tokens served from the provider&#x27;s prompt cache (typically discounted)</li></ul><h3 id="free-and-byok-requests" class="heading">Free and BYOK requests</h3><ul><li><strong>Free models</strong>: Models tagged with <code>:free</code> have zero cost -- usage is tracked but not billed</li><li><strong>BYOK requests</strong>: When using your own API key, the cost is set to $0 on Kilo&#x27;s side. You pay the provider directly based on your agreement with them</li></ul><h2 id="balance-management" class="heading">Balance management</h2><p>Model inference is deducted from your balance at the upstream provider&#x27;s rate with no markup. A 5% payment-processing fee applies when you purchase Kilo credits; the fee is charged separately and does not increase your balance. For example, $1 of purchased credits funds $1 of usage.</p><h3 id="individual-accounts" class="heading">Individual accounts</h3><p>Your account balance is the difference between total credits purchased and total usage. Check your balance in the <a href="https://app.kilo.ai">Kilo dashboard</a>.</p><p>When your balance reaches zero, requests to paid models will return HTTP 402 with a link to add credits:</p><div aria-live="polite" class="jsx-a274048045d91b66 code"><button type="button" aria-label="Copy code to clipboard" title="Copy code" class="jsx-a274048045d91b66 copy-button"><i class="codicon codicon-copy" style="font-size:1em;vertical-align:middle;display:inline" aria-hidden="true"></i></button><pre class="jsx-a274048045d91b66 language-json">{
  &quot;error&quot;: {
    &quot;message&quot;: &quot;Insufficient balance. Please add credits to continue.&quot;,
    &quot;code&quot;: 402,
    &quot;metadata&quot;: {
      &quot;buyCreditsUrl&quot;: &quot;https://app.kilo.ai/credits&quot;
    }
  }
}
</pre></div><h3 id="organization-accounts" class="heading">Organization accounts</h3><p>Organizations have their own balance pool that members draw from. Organization billing supports:</p><ul><li><strong>Shared balance</strong>: All members use a common credit pool</li><li><strong>Per-user daily limits</strong>: Cap individual member spending (e.g., $5/day per user)</li><li><strong>Auto top-up</strong>: Automatically replenish credits when the balance drops below a threshold</li><li><strong>Minimum balance alerts</strong>: Email notifications when the balance drops below a configured amount</li></ul><h2 id="organization-controls" class="heading">Organization controls</h2><p>Organizations can enforce policies on gateway usage for their members.</p><h3 id="model-allow-lists" class="heading">Model allow lists</h3><p>Restrict which models organization members can use:</p><div aria-live="polite" class="jsx-a274048045d91b66 code"><button type="button" aria-label="Copy code to clipboard" title="Copy code" class="jsx-a274048045d91b66 copy-button"><i class="codicon codicon-copy" style="font-size:1em;vertical-align:middle;display:inline" aria-hidden="true"></i></button><pre class="jsx-a274048045d91b66 language-undefined"># Examples of allow list entries
anthropic/claude-sonnet-4.5      # Specific model
anthropic/*                       # All Anthropic models
openai/gpt-5.2                   # Specific OpenAI model
</pre></div><p>The allow list supports exact matches and wildcard patterns. Requests for models not on the list return HTTP 403.</p><h3 id="provider-allow-lists" class="heading">Provider allow lists</h3><p>Restrict which inference providers can be used for routing. This is passed to the upstream router and affects which backends serve the request.</p><h3 id="data-collection-controls" class="heading">Data collection controls</h3><p>Organizations can set a data collection policy (<code>allow</code> or <code>deny</code>) that is applied to all requests from their members. Some free models require data collection to be allowed.</p><h3 id="per-user-daily-spending-limits" class="heading">Per-user daily spending limits</h3><p>Set a maximum daily spend per organization member. When a member reaches their daily limit, subsequent requests return a balance error. The daily limit resets at midnight UTC.</p><h2 id="rate-limiting" class="heading">Rate limiting</h2><h3 id="free-model-rate-limits" class="heading">Free model rate limits</h3><p>All free model requests (both anonymous and authenticated) are rate-limited by IP address:</p><div class="overflow-x-auto my-6 border border-neutral-300 dark:border-neutral-700 rounded-lg"><table class="w-full border-collapse text-sm"><thead class="bg-neutral-100 dark:bg-neutral-800/50"><tr class="border-b border-neutral-300 dark:border-neutral-700 last:border-b-0"><th class="px-4 py-2.5 text-left text-sm font-medium text-neutral-700 dark:text-neutral-300">Scope</th><th class="px-4 py-2.5 text-left text-sm font-medium text-neutral-700 dark:text-neutral-300">Limit</th></tr></thead><tbody class="bg-white dark:bg-neutral-900/50"><tr class="border-b border-neutral-300 dark:border-neutral-700 last:border-b-0"><td class="px-4 py-3 text-neutral-600 dark:text-neutral-400">Free models per IP</td><td class="px-4 py-3 text-neutral-600 dark:text-neutral-400">200 requests per hour</td></tr></tbody></table></div><p>When rate-limited, you receive HTTP 429:</p><div aria-live="polite" class="jsx-a274048045d91b66 code"><button type="button" aria-label="Copy code to clipboard" title="Copy code" class="jsx-a274048045d91b66 copy-button"><i class="codicon codicon-copy" style="font-size:1em;vertical-align:middle;display:inline" aria-hidden="true"></i></button><pre class="jsx-a274048045d91b66 language-json">{
  &quot;error&quot;: {
    &quot;message&quot;: &quot;Rate limit exceeded for free models. Please try again later.&quot;,
    &quot;code&quot;: 429
  }
}
</pre></div><h3 id="paid-model-limits" class="heading">Paid model limits</h3><p>Paid model requests are not rate-limited by the gateway itself, but may be rate-limited by upstream providers. Organization per-user daily spending limits provide an additional layer of cost control.</p><h2 id="usage-data" class="heading">Usage data</h2><p>Usage data is tracked per request and
