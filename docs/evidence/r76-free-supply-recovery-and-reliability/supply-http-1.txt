article-content mt-5"><article><h1 id="using-kilo-for-free" class="heading">Using Kilo for Free</h1><p>Kilo Code can be used completely free of charge. There are three places where Kilo uses AI model inference, and each can be configured to use free models.</p><h2 id="where-kilo-uses-models" class="heading">Where Kilo Uses Models</h2><ol><li><strong>Agentic interactions</strong> — Conversations with coding agents in IDE extensions (VS Code, JetBrains), CLI, and cloud services like Code Reviewer</li><li><strong>Autocomplete</strong> — In-editor code completions as you type (IDE extensions only)</li><li><strong>Background tasks</strong> — Automatic session titles and context summarization</li></ol><p>Each of these consumes credits by default. <strong>To use Kilo entirely for free, configure all three to use free models.</strong></p><h2 id="free-agentic-usage" class="heading">Free Agentic Usage</h2><p>Kilo provides free models for coding tasks through the Kilo Gateway and partner providers.</p><h3 id="auto-free" class="heading">Auto Free</h3><p>The easiest way to get started is <a href="/docs/code-with-ai/agents/auto-model"><strong>Auto Free</strong></a> (<code>kilo-auto/free</code>). This is a Kilo-provided model tier that automatically routes your requests to the best available free models — no configuration needed.</p><div class="my-4 border-l-4 border-l-yellow-500 bg-yellow-50 dark:bg-yellow-900/20 rounded-r-lg p-4"><div class="flex items-center gap-2 font-semibold text-yellow-700 dark:text-yellow-400 mb-2"><span class="text-yellow-500">⚠️</span><span class="uppercase text-sm tracking-wide">Data handling for Auto Free</span></div><div class="text-gray-700 dark:text-gray-300 [&amp;&gt;p]:m-0"><p>Auto Free may route your requests to providers that log prompts and outputs and use them to improve their services. Do not submit personal or confidential data when using Auto Free. In particular, it may route to NVIDIA&#x27;s free endpoints.</p><p>For NVIDIA free endpoints (Super/Ultra/etc): Trial use only - do not submit personal or confidential data. Your use is logged for security purposes and to improve NVIDIA products and services. The logged session data for improvement purposes is not linked to your identity or any persistent identifier. For more information about our data processing practices, see our <a href="https://www.nvidia.com/en-us/about-nvidia/privacy-policy/">Privacy Policy</a>. By interacting with this endpoint, you consent to our collection, recording, and use of such information and the <a href="https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf">NVIDIA API Trial Terms of Service</a>.</p></div></div><h3 id="finding-other-free-models" class="heading">Finding Other Free Models</h3><p>You can also browse and select individual free models. In the model picker, type <code>free</code> to filter the list — free models are clearly labeled across all platforms.</p><p><strong>In the IDE Extensions (VS Code, JetBrains):</strong></p><ol><li>Click on the current model below the chat window</li><li>Type <code>free</code> in the search box</li><li>Select any model labeled &quot;(free)&quot;</li></ol><p><strong>In the CLI:</strong></p><ol><li>Run <code>kilo</code> to open the CLI</li><li>Use the <code>/models</code> command</li><li>Type <code>free</code> to filter the list</li></ol><div class="my-4 border-l-4 border-l-gray-500 bg-gray-50 dark:bg-gray-800/50 rounded-r-lg p-4"><div class="flex items-center gap-2 font-semibold text-gray-700 dark:text-gray-300 mb-2"><span class="text-gray-500">📝</span><span class="uppercase text-sm tracking-wide">Note</span></div><div class="text-gray-700 dark:text-gray-300 [&amp;&gt;p]:m-0"><p>Some free models may be rate limited by the upstream provider. If you hit a rate limit, try switching to a different free model.</p></div></div><h3 id="cloud-tasks" class="heading">Cloud Tasks</h3><p>Kilo&#x27;s cloud services, including Code Reviewer, also support free models. Select any model labeled &quot;(free)&quot; in the model dropdown when configuring a cloud task.</p><div class="my-4 border-l-4 border-l-green-500 bg-green-50 dark:bg-green-900/20 rounded-r-lg p-4"><div class="flex items-center gap-2 font-semibold text-green-700 dark:text-green-400 mb-2"><span class="text-green-500">💡</span><span class="uppercase text-sm tracking-wide">Tip</span></div><div class="text-gray-700 dark:text-gray-300 [&amp;&gt;p]:m-0"><p>Available free models change over time as Kilo partners with different inference providers. Subscribe to our blog or join our <a href="https://kilo.ai/discord">Discord</a> for updates.</p></div></div><h2 id="free-autocomplete" class="heading">Free Autocomplete</h2><p>Kilo&#x27;s autocomplete feature provides AI-powered code completions as you type in IDE extensions.</p><p>By default, autocomplete routes through the Kilo provider and uses credits. If you run out of credits without a free alternative configured, autocomplete stops working — but your main coding workflow is unaffected.</p><h3 id="how-to-get-it-free" class="heading">How to Get It Free</h3><p>Add your own Mistral AI API key via <strong>BYOK (Bring Your Own Key)</strong> on the Kilo Gateway. Mistral offers a free tier for Codestral. When you configure a BYOK key, autocomplete requests use your key directly — at no cost on your Kilo balance.</p><p>See the <a href="/docs/code-with-ai/features/autocomplete/mistral-setup">Mistral Setup Guide</a> for step-by-step instructions.</p><h2 id="free-background-tasks" class="heading">Free Background Tasks</h2><p>Kilo uses a small model in the background for tasks like session titling. By default this is Auto Small, which consumes credits. If the small model is unavailable, Kilo falls back to your primary model — which may also consume credits if it&#x27;s a paid model.</p><p>To avoid credit usage for background tasks, set the small model to a free model:</p><p><strong>In the VS Code extension:</strong> Go to <strong>Settings → Models</strong> and change the small model to any free model.</p><p><strong>In the CLI:</strong> Set the <code>small_model</code> parameter in <code>~/.config/kilo/config.json</code>:</p><div aria-live="polite" class="jsx-a274048045d91b66 code"><button type="button" aria-label="Copy code to clipboard" title="Copy code" class="jsx-a274048045d91b66 copy-button"><i class="codicon codicon-copy" style="font-size:1em;vertical-align:middle;display:inline" aria-hidden="true"></i></button><pre class="jsx-a274048045d91b66 language-json">{
  &quot;small_model&quot;: &quot;your-preferred-free-model&quot;
}
</pre></div><p>Replace <code>your-preferred-free-model</code> with any free model from the model picker.</p><h2 id="related-resources" class="heading">Related Resources</h2><ul><li><a
