## Reusable truthful description

> CodeForge is a free-first autonomous software engineering platform for Windows, CLI, and editor workflows. Its runtime plans, edits, tests, reviews, and verifies code changes. CodeForge-managed free inference is routed through a zero-billing eligibility gate; user-provided credentials and paid inference are separate, explicit modes. We are building a durable capacity scheduler that measures provider quotas and moves unfinished work between eligible supply pools when one pool is exhausted. The public project is at https://github.com/Forger-Digital-Solutions/CodeForge.

The paragraph describes the product and active engineering direction. Do not present future broker or million-user control-plane goals as already certified. If an application asks for current production usage, use measured telemetry and deployment facts at submission time.
