# R33 provider quota-domain inventory

Checked 2026-09-24 against current official public documentation and the repository. The companion [JSON inventory](provider-quota-inventory.json) is the machine-readable record. This pass made **no authenticated provider API or inference requests**. Public numbers below are advertised ceilings and must not be used as actual CodeForge supply until plan, remaining capacity, route price, permission, and billing controls are verified.

The OpenRouter values are on [OpenRouter’s limits page](https://openrouter.ai/docs/api_reference/limits) and its [2026 free-model guide](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/). OpenRouter’s `/api/v1/key` reports `free_model_daily_requests.used/limit/remaining`; successful inference does not include `X-RateLimit-*` headers. Its [standard terms §7(4)](https://openrouter.ai/terms) restrict resale of model API access, while its [enterprise agreement](https://openrouter.ai/terms-of-service-enterprise) expressly addresses service to end customers. The current public terms also state that API use requires purchased credits, which is in tension with the free-account 50 RPD description; the actual account status needs direct read-only verification. No credit purchase is proposed here.

[Groq rate-limit documentation](https://console.groq.com/docs/rate-limits) says limits apply at the organization level. It exposes remaining RPD/TPM and reset values in response headers; the exact organization limits are in its console. [Groq’s current Services Agreement](https://console.groq.com/docs/legal/services-agreement) permits integration into a Customer Application for End Users (§3.1) and separately bars resale/sublicensing of Cloud Services (§6.3). CodeForge should treat a managed coding product as a customer application only after reviewing its exact product and plan against that distinction; it must not expose raw Groq API access.

[Cloudflare Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) establishes the daily Neuron pool and paid overage on Workers Paid. Its [limits](https://developers.cloudflare.com/workers-ai/platform/limits/) establish the 300 RPM default text-generation limit; [errors](https://developers.cloudflare.com/workers-ai/platform/errors/) distinguish `3036` exhausted daily allocation from `3040` temporary out of capacity and `5035` paid-only model. The [July 2026 changelog](https://developers.cloudflare.com/changelog/post/2026-07-28-models-require-workers-paid/) moved several coding-capable models to Workers Paid. A model’s presence in the catalog does not prove Free-plan eligibility.

[Gemini rate limits](https://ai.google.dev/gemini-api/docs/rate-limits) are per project, not key, with RPD resetting at Pacific midnight. [Gemini terms](https://ai.google.dev/gemini-api/terms) require Paid Services for API Clients available to EEA, Swiss, or UK users, and warn against sensitive/confidential data in Unpaid Services because submitted content may be used to improve Google products and reviewed by humans. A billing-linked project can satisfy the terms’ definition of Paid Services, but [spend caps can lag and allow overages](https://ai.google.dev/gemini-api/docs/billing/); that cannot be treated as a ForgeZero hard stop.

[SambaNova’s model limits](https://docs.sambanova.ai/docs/en/models/rate-limits) say Free Tier applies only without a linked payment method, list 20 RPD for its production free models, and expose RPM/RPD headers. Its preview models are for evaluation, not production. [Mistral’s usage page](https://docs.mistral.ai/admin/billing-usage/usage-limits) says monthly included usage, per-model RPS/TPM, and organization limits are account-specific; PAYG extends use. [Z.AI pricing](https://docs.z.ai/guides/overview/pricing) still lists three exact Flash IDs as Free, while newer Flash-branded IDs have paid token prices. [OpenCode Zen](https://opencode.ai/docs/en/zen/) lists changing, limited-time free routes and auto-reload settings. [Cerebras’s current FAQ](https://inference-docs.cerebras.ai/support/rate-limits) explicitly says its $5/30-day trial is not a permanent free tier. [Hugging Face pricing](https://huggingface.co/docs/inference-providers/en/pricing) grants $0.10 monthly free-user credit across routed providers, subject to change.

## Repository and credential observations

The catalog in `packages/model-registry/src/provider-definitions.ts` has adapters or definitions for the listed providers. The current process has variable **names present** for OpenRouter, Groq, Gemini, Cerebras, Mistral, and both Cloudflare account ID and API key. The inventory records only booleans, never secret values. Variable presence does not establish a production deployment secret, account ownership, free plan, capacity, or legal permission. SambaNova, Z.AI, Hugging Face, OpenCode, and NVIDIA variables checked here were absent; other secure credential stores were not inspected.

There is one material internal contradiction: `provider-definitions.ts` marks OpenRouter terms `CLEARED`, while `docs/legal/provider-terms-register.md` correctly classifies a CodeForge-owned shared hosted OpenRouter key as restricted without an enterprise agreement. A Free Capacity Broker must use the stricter hosted-use status. Groq’s current agreement is more nuanced than a blanket no-proxy rule: it expressly allows Customer Applications and End Users while prohibiting raw resale. The broker should represent those as different permissions.

No actual remaining requests/tokens, concurrency, failed-request charging, retry charging, observed throughput, account tier, or reset behavior was measured in this pass. Those fields remain `null` or explicitly unknown in JSON. There is no defensible sum of “total CodeForge capacity” from this inventory. In particular, adding 50 OpenRouter model listings, three Groq models, or multiple Cloudflare models would multiply catalog choices, not independent quota.

## Qualification sequence for the capacity broker

1. Confirm the credential’s **owner and quota domain**. User-owned BYOK must never be counted as shared CodeForge supply.
2. Read the account’s plan and actual quota dashboard or authenticated read-only quota endpoint. Record a timestamp, provider scope, model scope, remaining value, and reset semantics. Do not publish secrets or user identifiers.
3. Confirm exact route price, account billing/overage settings, and commercial hosted-use rights. Reject ambiguous status closed.
4. Capture response limit headers on already-authorized requests. Keep request/day, token/minute, and Neuron/credit counters separate; distinguish provider exhaustion from temporary model capacity.
5. Measure coding throughput and concurrency with bounded authorized workloads. Do not infer these from one HTTP 200 or public maxima.

The JSON intentionally uses `null` for unknown numeric capacity so downstream simulations cannot silently treat missing data as unlimited.
