# R14 Free Cloud Capacity Evidence

This directory holds sanitized, reproducible R14 capacity evidence. It is deliberately separate
from provider credentials, browser captures, and runtime logs. No screenshots are retained here
because dashboard captures can include API-key fragments, account identifiers, or billing data.

An evidence card records what a source actually established and what remains unknown. A provider
is not production-approved merely because it appears in this directory. ForgeAuto/Free requires
an `APPROVED` lifecycle, a `PRIVATE_CODE_ALLOWED` data policy for private repositories, an exact
$0 request price, and paid fallback disabled.

[ACCOUNT-CAPACITY-CARDS-2026-09-18.md](ACCOUNT-CAPACITY-CARDS-2026-09-18.md).
