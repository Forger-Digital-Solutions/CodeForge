# R54 handoff preservation

The Coder handoff is serial: the first child run has returned before the replacement starts. Both run in the same leased isolated worktree. A durable `role_quality_handoff` work item records the old route, changed file names, pending goal, verification obligations, and the replacement route/outcome. The new Coder's admission excludes the old route and uses the normal free eligibility, qualification, policy, and capacity gates. No unverified edit is integrated merely because a switch succeeded.

The deterministic test leaves a valid `partial()` edit in the first Coder's worktree, verifies that the replacement sees it, adds `finish()` without discarding `partial()`, and reaches the completion gate only after Reviewer and independent tests. The same mechanism must still be exercised on a live free model pair.
