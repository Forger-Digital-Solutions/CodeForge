# R53 role-quality adaptation

Production ranking combines a fresh role qualification receipt with bounded, decaying runtime evidence for that same role. `packages/eight-bit/test/r50-quality-routing-replay.test.ts` exercises the real Free Fabric decision path: repeated Reviewer failures make an alternative win; verified Reviewer completions later flip the winner back; a capacity-exhausted high-quality route yields without a quality penalty; a role floor cannot be bypassed by a positive score.

R53 closes a separate lifecycle gap. A fresh qualified receipt previously remained outside `pendingQualification()` despite repeated current runtime failure. Now three distinct failing run IDs after the receipt, with net negative role evidence, enqueue the model for governed requalification ahead of unrelated discovery. One failure cannot trigger it. Replayed evidence for one run is deduplicated. Provider 429/availability observations contain no role outcome and cannot trigger it. A verified role recovery can clear the urgency; a newly completed receipt starts a new evidence epoch. The existing provider daily request budget and per-cycle interval still bound probe spend.

The requalification queue respects free-price, connection, tool-support, terms, and private-code consent checks. This changes the schedule for a previously qualified route; it does not rewrite its receipt, bypass ForgeZero admission, or grant paid access. Actual benchmark failures must be scored by the existing suite before a role verdict changes.

The R53 live role-suite rerun for Nemotron Super was inconclusive when the provider interrupted the compact stage; Groq GPT-OSS 20B later returned 429s on Planner/Reviewer probes. Those capacity events are recorded as inconclusive and did not overwrite current receipts. Mistral Codestral 2508 completed the live suite and remained role-divergent: Explorer failed, Planner/Coder qualified, Reviewer probation.

The observed 429 continuation exposed a separate lifecycle defect: the role suite kept spending free requests on later cases after the first provider transient. R53 now stops there, leaves unattempted roles NOT_TESTED, and sets the composed receipt's transient flag so `FreeCloudService.qualifyPending()` retains the previous receipt. Deterministic tests cover interruption at Planner, interruption after one passing Reviewer case, and the composed retry signal. This change is a quota and evidence-correctness fix, not a role demotion.

Model identity remains keyed by exact provider and model ID. The catalog refresh test's rename/replacement scenario verifies that an old model is retired and a new ID appears without inheriting the old receipt. Alias continuity behind an unchanged upstream ID cannot be proven from catalog identity alone; runtime role evidence and governed requalification provide the bounded response to observed degradation.
