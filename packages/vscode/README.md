# CodeForge for VS Code

Free-first autonomous software engineering agent for VS Code. Connects the editor to a local
CodeForge server for starting sessions, sending messages, and viewing agent activity in a
webview.

## Status

This extension is not yet published to the VS Code Marketplace. See the repository root
[`README.md`](https://github.com/Forger-Digital-Solutions/CodeForge) for the CodeForge project
overview, and `LICENSE.pending` in this directory for current licensing status.

## Commands

- `CodeForge: Start Session`
- `CodeForge: Send Message`
- `CodeForge: Open Webview`
- `CodeForge: Stop Server`

## Configuration

- `codeforge.serverUrl` — URL of the CodeForge server (default `http://localhost:3210`)
